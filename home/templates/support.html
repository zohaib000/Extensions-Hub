Chrome extensions update automatically by default. To manually check for updates:
  1. Go to chrome://extensions/ in your browser
  2. Turn on "Developer mode" in the top right
  3. Click "Update" button
  4. Chrome will check for and install any available updates

Configuration Help

Accessing Extension Settings

Most of our extensions can be configured through:

  • Extension Popup: Click the extension icon in your toolbar
  • Options Page: Right-click the extension icon and select "Options"
  • Chrome Settings: Go to chrome://extensions/ and click "Details" then "Extension options"

Troubleshooting Guide

Common Issues and Solutions
Extension Not Loading
  • Check if the extension is enabled in chrome://extensions/
  • Reload the extension by clicking the refresh icon
  • Restart Chrome browser
  • Clear browser cache and cookies
Extension Missing from Toolbar
  • Click the puzzle piece icon in your toolbar
  • Pin the extension by clicking the pin icon
  • Alternatively, access via chrome://extensions/
Performance Issues
  • Disable other extensions temporarily to identify conflicts
  • Update Chrome to the latest version
  • Check if the website you're using is supported
  • Clear extension data in settings
Permission Errors
  • Grant all required permissions when prompted
  • Check site access settings in extension details
  • Reload the page after granting permissions
